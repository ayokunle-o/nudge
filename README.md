# Nudge

Tap the mic, talk, and Nudge pulls out what you need to remember. It checks in with you
three times a day (morning, afternoon, night) with whatever is still open, and fires
exact reminders for anything you gave a time.

- Voice is sent to Gemini with your own API key (Settings in the app) and turned into items.
- Everything is stored on the phone. Nothing else leaves the device.
- Every push to `main` builds a new APK and publishes it under Releases → `latest`.

Edit the app in `src/` (`index.html`, `styles.css`, `app.js`).
